#Інструкція з розгортання та запуску бота

-Для коректної роботи бота необхідно встановити бібліотеки для роботи з Telegram API та нейромережею. Виконайте команду в терміналі:
pip install aiogram==3.27.0 python-dotenv==1.2.2 google-generativeai==0.8.6 aiohttp==3.13.5

Згенеруйте власні ключі:
-Telegram Token: Створіть бота через @BotFather у Telegram та скопіюйте API Token.

-Google API Key: Перейдіть у Google AI Studio та отримайте ключ для доступу до моделі Gemini.

У  папці проєкту створіть файл із назвою .env. Додайте в нього ваші ключі у такому форматі, де є приклад у файлі .env.example 

Після налаштування ключів запустіть головний файл програми bot.py: python bot.py

📚 My Book Notes
Elevator Pitch: Це інтелектуальний Telegram-бот для читачів складних фентезі-творів, які стикаються з проблемою забування деталей сюжету та персонажів під час довгих перерв у читанні.На відміну від звичайних нотаток, цей ШІ-асистент на базі Gemini API автоматично структурує записи користувача, створюючи динамічну базу знань за допомогою патерну RAG.

🎯 Цільова аудиторія
Любителі багатотомних циклів та складних лонгрідів: Читачі творів із великою кількістю персонажів та заплутаними родинними зв'язками, де важливо не втрачати нитку сюжету.

Читачі з обмеженим часом: Люди, які читають короткими сесіями або з великими перервами. Бот допомагає їм миттєво "включитися" в контекст, не перечитуючи попередні розділи.

🛠 Технічна реалізація та ШІ-паттерни
Проєкт реалізований на базі Python 3.13 з використанням бібліотеки aiogram 3.x та моделі Gemini 1.5 Flash.

Ключові особливості:
RAG (Retrieval-Augmented Generation): Бот аналізує лише завантажені нотатки користувача. Це забезпечує високу точність і дозволяє уникнути спойлерів із загального інтернету.

Prompt Engineering (XML-теги): Для ізоляції інструкцій використано XML-тегування. Промпт налаштований так, щоб модель не використовувала зовнішні знання: «Працюй ТІЛЬКИ з текстом у тегах . Якщо відповіді немає — кажи: У нотатках про це не згадано».

UI/UX Оптимізація: Впроваджено статус «бот друкує...» (Latency Management) та обробку помилок (Graceful Degradation), що робить взаємодію стабільною та приємною.

Захист від Prompt Injection: Блок Retrieval виступає жорстким фільтром — бот не виконує шкідливі команди, оскільки ШІ не отримує даних для генерації сторонніх тем.

Валідація вводу: До коду додано валідатор довжини повідомлення. Тепер система відхиляє запити понад 1000 символів, захищаючи стабільність чату.

Memory & Context: Реалізовано систему збереження стану через FSMContext. Бот пам'ятає, на якому етапі додавання чи видалення нотатки знаходиться користувач.

Асинхронність: Повна підтримка asyncio дозволяє боту обробляти запити без затримок інтерфейсу.

Захист від Prompt Injection: У системний промпт інтегровано фільтри, які запобігають спробам користувача зламати роль бота або отримати доступ до системних інструкцій.

🚀 Інструкція із запуску
1. Попередні вимоги
Встановлений Python 3.13.

API-ключі від Telegram (BotFather) та Google AI Studio.

2. Встановлення
git clone https://github.com/ваш-нік/book-notes-bot.git
cd book-notes-bot

# Встановіть необхідні бібліотеки
pip install aiogram==3.27.0 python-dotenv==1.2.2 google-generativeai==0.8.6 aiohttp==3.13.5

3. Налаштування (.env)
Створіть файл .env у кореневій папці:
BOT_TOKEN=ваш_токен_телеграм
GOOGLE_API_KEY=ваш_ключ_gemini


4. Запуск
Bash
python bot.py

Frontend: Telegram UI.
Backend: Python сервер (модулі bot.py та rag_logic.py).

AI Layer: Google Gemini API з використанням паттерну доповнення контексту.
